# CODEX-AUTO-01 Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans inline, feature-first; no TDD or new standalone suite. Preserve existing acceptance work and use the independent Luna security reviewer.

**Goal:** Explicit remembered native permission reconnects existing-system and managed Codex accounts when Quotafern opens, without reinterpreting old consent.

**Architecture:** A native private authorization store owns versioned local account/connection/kind grants and a SHA-256 binding to the verified native identity (no raw identity, credential or path). Manual native consent offers Connect once / Connect and remember / Cancel. App startup lists remembered references, then invokes fixed native resume commands guarded by current policy, identity, cancellation and per-account supervision. Disconnect removes the grant; Quit only cancels runtime work.

**Tech Stack:** Existing Bun/Oxc/Svelte/Tauri/Rust stack; existing SHA-256 dependency becomes cross-platform. No additional services or raw credential access beyond existing consented adapters.

## Review focus

- A late consent/provider completion must never recreate a grant after Disconnect/removal.
- Renderer-forged metadata or command arguments cannot mint permission or change its native binding.
- Changed login/policy/source fails closed before quota publication, with no repeated dialogs or login loops.
