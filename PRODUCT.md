# Quotafern

<!-- impeccable:product-schema 1 -->

## Platform

web

The web interface is hosted in a cross-platform Tauri desktop popup; a browser preview supports development.

## Stack

User-selected Tauri 2, Rust, Svelte 5, TypeScript, Vite, Bun, Tailwind CSS 4, shadcn-svelte, Bits UI, and Lucide.

## Product Purpose

Monitor remaining AI subscription quotas from a compact system-tray application. F1 establishes the shell using fully synthetic examples only.

## Users and Operating Context

People using several AI coding subscriptions who want a quick remaining-quota check without leaving their desktop workflow.

## Capabilities and Constraints

Overview, Accounts, and Settings; separate palette and appearance preferences; explicit demo states; native tray Show, Hide, and Quit. Local-first, no telemetry, backend, credential discovery, provider requests, OAuth, release, or deployment during F1. A floating widget is deferred.

## Accessibility

Keyboard navigation, readable status text alongside color, system appearance, and reduced-motion support.

## Brand Commitments

Quotafern; compact Toolbox/Raycast/Linear-inspired utility. Graphite & Jade primary and Zinc & Signal alternative, each supporting light and dark.
